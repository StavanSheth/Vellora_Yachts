# VELORA — Private Worlds. Curated.

An editorial, quiet-luxury yachting experience rebranded from the mature architecture of Y.CO into **VELORA**.

## Brand Identity & Design System

- **Brand**: `VELORA`
- **Primary Tagline**: `PRIVATE WORLDS. CURATED.`
- **Hero Title**: `Yachts. Beyond the Expected.`
- **Visual Aesthetic**: Quiet Luxury, Editorial, High-End Travel, Warm Light.

### Color Tokens

```css
:root {
  --velora-jade:   #123C36; /* Primary: Deep Jade (25%) */
  --velora-teal:   #1F5A50; /* Secondary: Forest Teal */
  --velora-ivory:  #F5F1E8; /* Main Background: Warm Ivory (60%) */
  --velora-sand:   #DDD4C3; /* Secondary Background: Sandstone (10%) */
  --velora-carbon: #151817; /* Main Text: Carbon */
  --velora-brass:  #A88955; /* Accent: Muted Brass (5% fine accents) */
  --velora-white:  #FCFBF7; /* Soft White */
}
```

### Typography

- **Headlines & Display**: `Playfair Display` (editorial serif)
- **UI, Body & Navigation**: `Inter` (refined modern sans-serif)

### Curated Superyacht Imagery

All non-yacht, generic, or off-brand imagery (airplanes, yellow ropes, generic garden/office photos) have been replaced across all templates with prominent, world-famous superyachts:
- **76m Mega-yacht *Wheels***: Cruising the Mediterranean *(Yacht Management)*
- **57m Custom Feadship *Halo***: Cruising the French Riviera *(Charter Management)*
- **85m Silver Yachts Explorer *Bold***: Navigating Norwegian fjords *(Curated Features)*
- **81m Royal Huisman Schooner *Sea Eagle***: Under full spread of sails *(Lifestyle)*
- **83.5m Hybrid Feadship *Savannah***: Award-winning architectural marvel *(Build & Refit)*
- **77m Feadship *Boardwalk***: Cruising off the coast of Monaco *(Sales & Purchase)*
- **78m Lürssen *Rocinante***: Anchored in pristine Caribbean waters *(Advisory)*
- **70m Exploration Yacht *Sherakhan***: Cruising remote polar waters *(Expeditions)*
